# Code of Conduct

Relay is built by people with different backgrounds, skills and opinions. We want everyone who takes part in this project to feel welcome and safe.

## Our standard

This project adopts the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/) as its code of conduct.
The full text at that link applies to all project spaces: the repository, issues, pull requests, Discussions, and any chat or event run in the
project's name. It also applies when someone represents the project in public.

In short, we expect participants to:

- be respectful and considerate, including when they disagree;
- give and accept constructive feedback gracefully;
- focus on what is best for the community and its users;
- take responsibility for mistakes and learn from them.

Harassment, insults, discriminatory language or imagery, personal or political attacks, publishing other people's private information, and any other
conduct that would be inappropriate in a professional setting are not acceptable.

## Reporting

If you experience or witness unacceptable behaviour, contact the maintainer privately through their GitHub profile
(<https://github.com/marekbdzoch>), or open a confidential report via the repository's **Security → Report a vulnerability** form and
mark it as a conduct report.

Please include what happened, where and when, and links or screenshots if you have them. All reports are reviewed promptly and handled
confidentially. Reporters will not face retaliation.

If a maintainer is involved in the incident, you can contact any other maintainer directly.

## Enforcement

Maintainers are responsible for clarifying and enforcing this code of conduct. They will follow the
[enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines) of the Contributor Covenant
(correction, warning, temporary ban, permanent ban), choosing the response that fits the situation. Maintainers may remove, edit or reject comments,
commits, code, issues and other contributions that violate this code of conduct.
